Narrative Flow of Data

To use AgentA, the End User signs in through process 1.0 Login, which checks account details in D1 User Accounts and asks the Device for a biometric unlock; the active session is kept in D5 Session, can be restored while it is still saved, and is cleared again when the user signs out. New users go through 2.0 Registration, which stores a new account in D1 User Accounts and returns a one-time recovery code to the End User. If a password is forgotten, 3.0 Forgot Password sends a code request to Email, the End User enters the one-time code and a new password, and the updated password is written back to D1 User Accounts. Signed-in users chat through 4.0 Chat, which saves every new chat in D2 Chats and every new message in D3 Messages; deleting a chat removes it from D2 Chats; when the connection is online the chat request goes to the AI Service (Online), which returns the AI reply, and when offline the reply comes from the offline AI model held in D4 AI Model. Image requests pass through 5.0 Image Generation, which asks the AI Service for the picture and saves the finished image in D3 Messages so it stays part of the chat. On first use, 6.0 Model Download fetches the AI model file from the AI Service, shows download progress to the End User, and saves the model in D4 AI Model until it is ready. Finally, 7.0 Profile & Account sends profile changes and a new password to D1 User Accounts, and confirms every change back to the End User; deleting the account also clears the saved session from D5 Session.
