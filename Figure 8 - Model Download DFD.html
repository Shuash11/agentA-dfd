LEVEL 2 DFD PROCESS 6.0 (MODEL DOWNLOAD)

Figure 8. Level 2 DFD Process 6.0 (Model Download)

Narrative Flow of Data

The download begins when the End User taps to start it, and process 6.1 Start Download takes the download request. Process 6.1 sends the model file request to the AI Service (Online), which returns the AI model file to 6.3 Save Model. While the file arrives, the started download moves to 6.2 Show Progress, which shows download progress back to the End User. The finished download passes from 6.2 to 6.3 Save Model, which saves the model as a saved model in D4 AI Model. Finally, the stored model moves to 6.4 Confirm Model Ready, which tells the End User that the model is ready, and the app can then keep working offline.
