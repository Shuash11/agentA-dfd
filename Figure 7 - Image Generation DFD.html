LEVEL 2 DFD PROCESS 5.0 (IMAGE GENERATION)

Figure 7. Level 2 DFD Process 5.0 (Image Generation)

Narrative Flow of Data

Image generation starts when the End User types an image prompt, and process 5.1 Enter Image Prompt takes the typed prompt. The entered prompt moves to 5.2 Check Connection, which checks whether the device is online and passes an online check to 5.3 Request Image. Process 5.3 sends the image request to the AI Service (Online), which generates the picture and returns the generated image to 5.3. The finished image flows into 5.4 Show Generated Image, which shows the picture to the End User. When the user keeps it, the shown image moves to 5.5 Save Image to Chat, which saves it as a saved image in D3 Messages so it stays part of the chat.
