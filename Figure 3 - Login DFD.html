LEVEL 2 DFD PROCESS 1.0 (LOGIN)

Figure 3. Level 2 DFD Process 1.0 (Login)

Narrative Flow of Data

When the End User opens the app, process 1.1 Choose Sign-In Method starts the login by offering either a password sign-in or a biometric unlock. Choosing the password route moves to 1.2 Enter Credentials, where the user types the sign-in details, and the typed credentials flow into 1.3 Verify Credentials. Verification checks the account details kept in D1 User Accounts, and once the details match, a verified sign-in moves on to 1.5 Open Dashboard. Choosing the biometric route goes to 1.4 Unlock with Biometric, which sends an unlock request to the Device and continues only after the Device returns a successful unlock result. When the dashboard opens, 1.5 Open Dashboard shows the sign-in confirmation back to the End User and writes a new session into D5 Session, while an earlier saved session can also be read from D5 Session when the app starts again. Finally, 1.6 Sign Out ends the active session and clears the saved session from D5 Session.
