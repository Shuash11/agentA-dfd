Figure 1. Context Diagram of the AgentA System

Narrative Flow of Data

Figure 1 shows the AgentA AI Skill Coach system as one process, numbered 0, together with the four outside parties it exchanges data with. The End User signs in or creates an account by sending sign-in details and sign-up details to process 0, and while using the app the same user sends chat messages and image prompts. Process 0 answers the End User with AI replies and generated images. When the phone is online, process 0 sends chat requests, image requests, and model file requests to the AI Service (Online), and the AI Service returns AI replies, generated images, and the AI model file in response. When a password is forgotten, process 0 sends a code request to Email, and Email returns a one-time code that the user types back into the app to set a new password. Process 0 also asks the Device to check the user's fingerprint or face by sending an unlock request, and the Device answers with the unlock result that lets the user back into the app. Every action shown here begins with the End User, and every answer reaches the End User through process 0.
