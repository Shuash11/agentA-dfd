Narrative Flow of Data

The End User is the only person outside the system. The End User sends its sign-up details, sign-in details, chat message, profile details and reset request into AgentA to sign up, sign in, chat, manage the profile and account, and recover a forgotten password. AgentA checks each request and sends the results back to the End User.
