CONTEXT DIAGRAM

Figure 1. Context Diagram of the AgentA System

Narrative Flow of Data

The diagram shows AgentA as one process, numbered 0, and that single process is the whole system. Four outside parties work with it. The End User signs in or signs up by sending sign-in details and sign-up details to process 0, and sends chat messages, profile details and a reset request while using the app. Process 0 answers the End User with AI replies and a confirmation that the password changed. When the device is online, process 0 sends a chat request to the AI Service (Online) and receives the AI reply back. When a password is forgotten, process 0 sends a code request to Email, and Email returns a one-time code. Process 0 also sends an unlock request to the Device, and the Device sends back the unlock result so the End User can get in.
