Figure 2. Level 0 DFD (Diagram 0) of the AgentA System

Narrative Flow of Data

The End User is the only person using the app. 1.0 Register is where the user signs up and a new account is created. 2.0 Login signs the user in. 3.0 Chat is where the user sends and reads messages. 4.0 Profile & Account lets the user view and change the profile and account. 5.0 Forgot Password recovers the account if the user forgets their password, and once the password is reset the user returns to 2.0 Login to sign in with the new password. These five processes are the user's main functions, drawn here in the order the user meets them. The data stores behind each function and the detail inside every process appear in the Level 2 figures that follow.
