LEVEL 2 DFD PROCESS 4.0 (PROFILE & ACCOUNT)

Figure 6. Level 2 DFD Process 4.0 (Profile & Account)

Narrative Flow of Data

Profile management starts when process 4.1 View Profile reads the account details kept in D1 User Accounts and shows the profile details to the End User. The opened profile moves to 4.2 Edit Profile, where the End User changes the profile details and sends the profile changes. The changed profile flows into 4.3 Save Changes, which writes the updated account back into D1 User Accounts. The saved profile continues to 4.4 Change Password, where the End User enters a new password to update. The updated password moves to 4.5 Delete Account, where the End User can send a delete request; when the account is deleted, the cleared session is removed from D5 Session. Finally, the deleted account message goes to 4.6 Confirm Deletion, which shows the confirmation to the End User.
