LEVEL 2 DFD PROCESS 3.0 (CHAT)

Figure 5. Level 2 DFD Process 3.0 (Chat)

Narrative Flow of Data

When the End User opens the chat area, process 3.1 Open Chat List reads the chat list from D2 Chats and the message history from D3 Messages, and shows the chat history back to the End User. Creating a new chat through 3.2 Create New Chat saves a new chat in D2 Chats, and the created chat moves on to 3.3 Enter Message. There the End User types a chat message, and the composed message flows into 3.4 Select AI Engine. Process 3.4 chooses the AI engine, using the offline AI model stored in D4 AI Model when the device is offline, and sends the chat request to the AI Service (Online) when the device is online. The AI Service returns the AI reply to 3.5 Receive AI Reply, which shows the AI reply to the End User and saves the conversation as new messages in D3 Messages. Finally, 3.6 Delete Chat removes a chat from D2 Chats when the user deletes it.
