LEVEL 2 DFD PROCESS 2.0 (REGISTRATION)

Figure 4. Level 2 DFD Process 2.0 (Registration)

Narrative Flow of Data

Registration starts when the End User opens the sign-up page; process 2.1 Enter Sign-Up Details takes the sign-up details that the user types, such as an email address and a password. The completed form flows into 2.2 Submit Registration, which creates the account and sends the new account into D1 User Accounts. Once the account exists, the account created message moves to 2.3 Display Recovery Code, which shows the one-time recovery code on the screen. The recovery code flows back to the End User, who is asked to keep it safe for recovering the account later. With the account safely stored in D1 User Accounts and the recovery code in the user's hands, the registration is complete.
