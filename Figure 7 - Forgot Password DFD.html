LEVEL 2 DFD PROCESS 5.0 (FORGOT PASSWORD)

Figure 7. Level 2 DFD Process 5.0 (Forgot Password)

Narrative Flow of Data

When the End User forgets a password, process 5.1 Enter Email takes the email address typed on the reset screen. The entered email flows into 5.2 Request Code, which sends a code request to Email and asks for a one-time code to be delivered. The Email entity sends the one-time code to 5.3 Enter Code, and the End User types that same one-time code to continue. The typed code flows into 5.4 Verify Code, which checks the code and passes a verified code on to 5.5 Set New Password. The End User types a new password into 5.5, which sends the updated password into D1 User Accounts. Finally, the password set result moves to 5.6 Confirm Password Changed, which shows the password changed confirmation back to the End User.
